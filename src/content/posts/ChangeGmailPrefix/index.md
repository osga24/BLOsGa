# 前言

很多人的 gmail 帳號都是小時候家人或學校幫忙辦理的

像是 `a09xxxxxxxx@gmail.com`、`chenjiahao20260623@gmail.com` 之類的

長大之後要拿來寄履歷、聯絡公司、註冊正經的服務，每次寄信出去都不太好意思，登入帳號每次都打很長一串

以前的解法都是「重新註冊一個 Gmail，然後把所有信件、聯絡人慢慢搬過去」，光想到就好累

但其實現在 Google 已經支援「直接更改 Gmail 前綴」了！同一個帳號、所有信件聯絡人通通保留，只是把 `@` 前面那串換掉而已

# 可以改與不能改的情況

## 可以改

- 把 `@gmail.com` 結尾的地址改成「另一個還沒被人用的 `@gmail.com`」
- 從非 Gmail 帳號新增一個 Gmail 地址
- 把 Gmail 移除，改用非 Gmail 地址

# 怎麼改

直接前往 [myaccount.google.com/google-account-email](https://myaccount.google.com/google-account-email)

往下滑找到「**Google 帳戶電子郵件地址**」，如果你的帳號符合資格，旁邊會出現一個可以點的「**變更**」

<div class="info">

如果你看不到變更選項，通常是以下幾種情況：

- 帳號是學校 / 公司管理的
- 帳號剛建立沒多久
- 最近曾經改過（有頻率限制，下面會講）

</div>

點下去之後，輸入你想要的新使用者名稱，例如 `osga@gmail.com`

如果有人用過了，它會跟你說這個不能用，要換一個

確認之後送出，Google 就會把你的登入信箱換成新的，舊的會自動轉成「備用地址」

<div class="info">
帳號要求要六個字元以上
</div>

# 改完之後會發生什麼事

這部分滿酷的，Google 考量到很多問題：

- **舊地址不會壞掉**：別人繼續寄信到你舊的 `chenjiahao20250623@gmail.com`，還是會進到你同一個收件匣
- **登入可以用新的也可以用舊的**：兩個地址都能登入同一個 Google 帳號
- **所有信件、雲端硬碟、相簿、YouTube 通通不動**：因為帳號本身沒換，只是換個名牌而已

換句話說，這個操作對外是「我換了一個新的寄件地址」，對內是「全部資料一個都沒少」

# 限制

這邊要特別注意，Google 對這個功能設了不少限制，不是讓你隨便玩的：

- **每 12 個月只能建立一次新的 `@gmail.com` 地址**
- **整個帳號生涯總共最多三次**
- **一個帳號最多同時擁有四個地址**
- **舊地址無法刪除**，只能擺著當備用

所以建議你想好之後再改，不要先改一個過渡用的、之後又想換成更好的，因為配額用完就沒了

# 一些容易踩到的坑

## Chromebook 使用者

如果你是用 Chromebook，並且這個 Google 帳號是你登入 Chromebook 的主帳號，改完之後可能會需要重新登入裝置

## 用 Google 帳號登入的第三方服務

很多服務（Notion、Figma、Spotify 之類）都支援「使用 Google 帳戶登入」

改完前綴後，大部分服務還是會用同一個 Google 帳號識別你，但少數服務會用「email 字串」當作 user 識別，這時候可能會出現登入後變成「新使用者」的狀況

實際操作前，建議先想一下自己有沒有用 Google 登入特別重要的服務，必要的話可以先用舊信箱登入該服務後，去設定裡把帳號的 email 改掉

# 結語

如果你也跟我一樣，當年取了一個現在會想埋進土裡的 Gmail，又懶得整個搬家，這功能真的算救星

唯一要注意的就是配額用完就沒了，所以下定決心之後再改，不要當改名遊戲在玩
